```
Step 13: Create TemplatesManager component
Step 14: Update UpcomingResetsWidget with real data
Step 15: Build verification + documentation updates
```

## 4.2 Key Design Decisions

1. **Database migration required.** Four new tables must be created via inline migration in database.cjs (same pattern as Phase 14).

2. **Quota tracking is account/provider-level.** Quotas link to accounts or providers, not individual models.

3. **Notifications are generated by services.** When a quota threshold is hit, when a backup completes, etc., the service creates a notification record.

4. **Favorites use unique constraint.** (entity_type, entity_id) prevents duplicate favorites.

5. **Templates store config as JSON string.** Same pattern as the Master Blueprint specification.

7. DATABASE CHANGES
================================================================================

**Migration required.** Four new tables must be added via inline CREATE TABLE IF NOT EXISTS in database.cjs.

### quotas table
```sql
CREATE TABLE IF NOT EXISTS quotas (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entity_type TEXT NOT NULL,
  entity_id INTEGER NOT NULL,
  quota_type TEXT NOT NULL,
  limit_value REAL NOT NULL,
  current_value REAL NOT NULL DEFAULT 0,
  reset_interval TEXT,
  reset_day INTEGER,
  last_reset TEXT,
  next_reset TEXT,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_quotas_entity ON quotas(entity_type, entity_id);
CREATE INDEX IF NOT EXISTS idx_quotas_type ON quotas(quota_type);
```

### favorites table
```sql
CREATE TABLE IF NOT EXISTS favorites (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  entity_type TEXT NOT NULL,
  entity_id INTEGER NOT NULL,
  sort_order INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now')),
  UNIQUE(entity_type, entity_id)
);
CREATE INDEX IF NOT EXISTS idx_favorites_entity ON favorites(entity_type, entity_id);
```

### templates table
```sql
CREATE TABLE IF NOT EXISTS templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  entity_type TEXT NOT NULL,
  config TEXT NOT NULL,
  is_default INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now')),
  updated_at TEXT DEFAULT (datetime('now'))
);
```

### notifications table
```sql
CREATE TABLE IF NOT EXISTS notifications (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  type TEXT NOT NULL,
  title TEXT NOT NULL,
  message TEXT,
  entity_type TEXT,
  entity_id INTEGER,
  is_read INTEGER DEFAULT 0,
  created_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_notifications_type ON notifications(type);
CREATE INDEX IF NOT EXISTS idx_notifications_read ON notifications(is_read);
```

8. IPC/DATA FLOW
================================================================================

## 8.1 Quota Flow
```
QuotaManager → useQuotas hook → ipc.quotas.list() → IPC → quotaRepository → DB
Quota threshold hit → notificationService.notify() → notifications table → NotificationDisplay
```

## 8.2 Notification Flow
```
Service event → notificationService.create() → notifications table
NotificationDisplay → useNotifications hook → ipc.notifications.list() → IPC → notificationRepository → DB
Mark read → ipc.notifications.markRead(id) → DB update
```

## 8.3 Favorite Flow
```
Entity page → "Pin" button → useFavorites.add() → ipc.favorites.add() → IPC → favoriteRepository → DB
Sidebar → useFavorites.list() → ipc.favorites.list() → IPC → favoriteRepository → DB
```

## 8.4 Template Flow
```
Entity page → "Save as Template" → useTemplates.create() → ipc.templates.create() → IPC → templateRepository → DB
Create from template → useTemplates.createFromEntity() → ipc.templates.createEntity() → entity IPC → DB
```
