4. IMPLEMENTATION STRATEGY
===============================================================================

Split into 4 sub-features, implemented bottom-up (dependencies first):

  Sub-feature A: Tags Module (backend complete, frontend missing)
  Sub-feature B: Notes Module (backend complete, frontend partial)
  Sub-feature C: Search System (no backend needed, client-side)
  Sub-feature D: Command Palette (UI component + keyboard wiring)

Order: A → B → C → D

Rationale:
  - Tags is simplest (CRUD only, no editor complexity)
  - Notes builds on tag patterns and adds editor
  - Search depends on all entities existing (tags/notes complete first)
  - Command palette depends on navigation + entity creation being available

9. DATA FLOW
===============================================================================

### Search Flow

  User types in SearchInput
    → 150ms debounce
    → useSearch hook fires Promise.allSettled across all entity APIs
    → Each IPC call: api.{entity}.list({search: query})
    → Renderer IPC client → preload bridge → IPC handler
    → Repository search() method (LIKE query)
    → Results grouped by entity type
    → SearchResults renders grouped display

### Notes Flow

  Notes Page → useNotes hook → api.notes.list(filters)
    → IPC → NoteRepository.findAllWithRelations()
    → Joins agent/project names
    → Returns notes with relation names

  Note Editor → auto-save → useNotes.update mutation
    → api.notes.update(id, {content})
    → IPC → NoteRepository.update()

### Tags Flow

  Tags Page → useTags hook → api.tags.list()
    → IPC → TagRepository.findAll()
    → Returns all tags

  Entity Detail → tag assignment → useTags.addToEntity mutation
    → api.tags.addToEntity(entityType, entityId, tagId)
    → IPC → TagRepository.addToEntity()
    → Invalidates entity query

### Command Palette Flow

  User presses Cmd+K
    → useKeyboardShortcuts triggers command-palette-store.togglePalette()
    → command-palette-store sets isOpen=true
    → command-palette Dialog opens
    → User types to filter commands
    → User selects command (Enter/click)
    → Command action executes (navigate / open dialog)
    → Palette closes

10. VALIDATION AND ERROR HANDLING
===============================================================================

### Validation
  - Tag form: TagFormSchema (name required, 1-50 chars, unique; color optional)
  - Note form: NoteFormSchema (title optional, 200 chars; content optional, 50000 chars)
  - Search: No validation needed (free text, debounced)

### Error Handling
  - All hooks return { data, isLoading, error } from React Query
  - Components show ErrorState on error
  - Components show EmptyState when no data
  - Components show LoadingState/skeleton during load
  - Search uses Promise.allSettled — partial failures don't break results

### Cache Invalidation
  - Tag mutations invalidate ['tags'] query key
  - Note mutations invalidate ['notes'] query key
  - Tag assignment invalidates both ['tags'] and entity query key
  - Search does not cache (real-time query)

### Confirmation Dialogs
  - Delete tag: ConfirmDialog before deletion
  - Delete note: ConfirmDialog before deletion
  - Unsaved note changes: confirm before navigating away
