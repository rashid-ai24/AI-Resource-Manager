# Features

## Overview

AI Resource Manager v2 provides comprehensive management of AI-related resources with a premium, offline-first experience.

## Core Features

### Agent Management

Manage AI agents with full CRUD operations:

- Create, read, update, delete agents
- Track agent metadata (name, description, status)
- Associate agents with providers and models
- Add notes and tags to agents
- View agent activity history

### Provider Management

Organize AI service providers:

- Support for multiple providers (OpenAI, Anthropic, etc.)
- Track provider details (name, description, API endpoint)
- Manage provider-specific settings
- Associate providers with models

### Model Management

Track AI models with detailed metadata:

- Model name, ID, and description
- Context window and token limits
- Cost per token (input/output)
- Supported capabilities (vision, tools, etc.)
- Provider association

### Account Management

Manage API accounts and billing:

- Track account details
- Monitor usage and costs
- Associate accounts with providers
- Support for multiple accounts per provider

### API Key Management

Securely store and manage API keys:

- Encrypted storage
- Key rotation tracking
- Usage monitoring
- Association with accounts

### Project Management

Organize resources by project:

- Create projects to group related resources
- Associate agents, providers, models with projects
- Track project-specific usage and costs
- Project-level notes and tags

## Organization Features

### Tags

Categorize and filter resources:

- Create custom tags with colors
- Add multiple tags to any entity
- Filter list views by tags
- Tag-based organization

### Notes

Add notes to any entity:

- Rich text notes
- Automatic timestamps
- Entity-specific notes
- Searchable notes

### Search

Global search across all entities:

- Search by name, description, ID
- Filter by entity type
- Recent search history
- Quick results

## Analytics Features

### Usage Tracking

Monitor AI usage:

- Token usage over time
- Cost tracking by provider/model
- Usage patterns and trends
- Historical data

### Cost Analysis

Track and analyze costs:

- Cost by provider
- Cost by model
- Cost by project
- Cost trends over time

### Activity Logging

Track all activities:

- Automatic activity logging
- Activity history per entity
- Recent activity feed
- Activity statistics

### Command Palette

- Navigate to any page
- Create new entities
- Search across all data
- Access recent items

### Keyboard Shortcuts

Efficient keyboard navigation:

- Ctrl+K: Command Palette
- Ctrl+1-9: Quick navigation
- Ctrl+N: Create new
- Ctrl+F: Focus search
- Escape: Close modals

### Responsive Design

Modern, responsive interface:

- Adaptive layouts
- Dark/light theme support
- Smooth animations
- Accessible design

### Backup & Restore

Protect your data:

- Create manual backups
- Automatic backup reminders
- Restore from backup
- Export/import data

### Settings

Customize the application:

- Theme selection

### Local Storage

All data stored locally:

- SQLite database

- Full user control
- Privacy-focused

### API Key Security

- Local storage only
- No transmission to external services
- Encrypted at rest
- Access logging
